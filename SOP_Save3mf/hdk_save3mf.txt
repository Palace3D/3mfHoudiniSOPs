= Save3mf =

#type: node
#context: sop
#internal: hdk_save3mf

"""Saves geometry to disk as a 3mf file."""

== Overview ==

Save3mf writes the incoming geometry out as a 3mf file, following
the 3mf Core Specification and most of the 3mf Materials
Specification. It supports per-point, per-vertex, per-primitive, and
detail color, along with file-based and base-color textures.

The whole input is currently written out as a single 3mf object.

TIP:
    You can drive the Mesh Name, File Name, Title, Description, and
    Designer from upstream data instead of typing them in by hand.
    Add a Detail Wrangle before this node and set the string detail
    attributes `out_mesh`, `out_filename`, `out_title`,
    `out_description`, and `out_designer` to whatever your setup
    computes. This lets you compute the strings directly in
    VEX from the geometry's own attributes and content, rather than
    having to reference that data back through a parameter
    expression.

    If you leave the corresponding parameter blank, the detail
    attribute is used. If you type a value directly into the
    parameter, that value always wins over the attribute, and the
    node shows a warning saying the attribute was ignored. Mesh
    Name, File Name, and Title have default values, so clear them to
    use the attributes.

    These mirror the `in_title`, `in_description`, and `in_designer`
    detail attributes that [Node:sop/hdk_read3mf] sets from a file's
    metadata. To keep a file's metadata when you read it and save it
    back, copy them across in a Detail Wrangle, for example
    `s@out_title = s@in_title;`.
    (`out_meshname` also still works for the mesh name, for setups
    made with earlier versions.)

@parameters

Flip Normals:
    #id: flip
    Flip Houdini normals to match 3mf's winding order, which is
    opposite Houdini's.

Uses Shader Override:
    #id: usedShaderOverride
    Use a single shader across many textures. Intended for parts
    that were imported via [Node:sop/hdk_read3mf] with its own
    Shader Override option enabled, so the per-primitive texture
    assignments captured on import (in the `material_override`
    attribute) are read back out correctly on export.

Convert sRGB:
    #id: convertSRGB
    Encode Houdini's linear `Cd` colors as sRGB when writing them,
    since 3mf colors are sRGB by the spec. With this on, colors look
    the same in a slicer, in other viewers, and on the printed part
    as they did in Houdini's viewport. Applies to point, vertex,
    primitive, and detail colors, and to the base color of plain
    (non-texture) shaders. Texture image files are not changed. On
    by default. Turn it off only to reproduce files written by
    Save3mf 3.0 or earlier, which wrote the linear values
    unconverted.

Debug:
    #id: debug
    Print extra diagnostic information to the console (`std::clog`)
    while saving. Hidden by default, since this is intended for
    development/troubleshooting rather than everyday use.

    NOTE:
        To turn this on, right-click the node and choose Parameters
        and Channels > Edit Parameter Interface. Under Existing
        Parameters, turn on "Show Invisible Parameters" — Debug
        will then appear in that list. Click it, then turn off the
        "Invisible" toggle on its Parameter Description. This makes
        the toggle visible on this one node instance only —
        dropping a new Save3mf node still starts with Debug hidden.

Timer:
    #id: timer
    Report how long the save operation took.

Debug Files:
    #id: debugfiles
    Leave the intermediate files (before they're zipped into the
    final `.3mf`) in your temp folder for inspection, instead of
    cleaning them up after the save.

Mesh Name:
    #id: mesh
    Name given to the mesh inside the 3mf file. Overridden by the
    `out_mesh` detail attribute if this is left blank — see the tip
    above.

File Name:
    #id: filename
    Path to the 3mf file to write. A `.3mf` extension is added
    automatically if not already present. Overridden by the
    `out_filename` detail attribute if this is left blank — see the
    tip above.

Title (optional):
    #id: title
    Optional title written into the 3mf file's metadata header.
    Overridden by the `out_title` detail attribute if this is left
    blank — see the tip above.

Description (optional):
    #id: description
    Optional description written into the 3mf file's metadata
    header. Overridden by the `out_description` detail attribute if
    this is left blank — see the tip above.

Designer (optional):
    #id: designer
    Optional designer name written into the 3mf file's metadata
    header. Overridden by the `out_designer` detail attribute if
    this is left blank — see the tip above.

Save:
    #id: saveBtn
    Triggers the actual write. Save3mf only writes geometry when
    this button is pressed — simply having the node in the network
    does not write a file.
